一、獎勵圖位置（在琴鍵上居中）

和網站一樣大小的琴鍵（電腦版）。藍色虛線 = 圖片底部到琴鍵底線的距離。彩紙會一直重播。

20%

1底部離琴鍵底 20%

圖片底部到琴鍵底線的距離 = 圖片高度的 20%。

30%

2底部離琴鍵底 30%

圖片底部到琴鍵底線的距離 = 圖片高度的 30%。

40%

3底部離琴鍵底 40%

圖片底部到琴鍵底線的距離 = 圖片高度的 40%。

50%

4底部離琴鍵底 50%

圖片底部到琴鍵底線的距離 = 圖片高度的 50%。

二、正確音閃爍（卡片圖形 + 琴鍵圖形一起動）

先選速度，下面 10 種動態都會用這個速度播放。

→

1彈跳發光

現在用的：往上跳一下再小跳一下，帶一點粉色光。

→

2呼吸

慢慢變大再慢慢變小，像在呼吸，最安靜。

→

3漂浮

輕輕往上飄、再落回來，像氣球。

→

4搖擺

左右輕輕搖，像在跟音樂打拍子。

→

5心跳

咚咚跳兩下，然後休息，節奏感強。

→

6果凍

壓扁再彈回來，Q 彈好玩。

→

7光暈

不移動，只有粉色光慢慢亮起再暗下。

→

8轉一圈

慢慢轉一圈，停一下，再轉。

→

9跳跳落地

蹲一下、跳起來、落地時壓扁一點。

→

10忽明忽暗

顏色慢慢變淡再變回來，最溫和。
